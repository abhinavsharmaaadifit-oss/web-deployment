## Preview / hosting

Each page is a self-contained `index.html` file with inline CSS and JavaScript. The HTML files can be opened locally in a browser. To publish a page under GitHub Pages in the existing `web-deployment` repository, copy its individual folder into the repository's `sites/` directory and commit the changes.

With GitHub Pages source set to `main` / `/(root)`, the URL pattern is:

`https://abhinavsharmaaadifit-oss.github.io/web-deployment/sites/<slug>/`

Example:

`https://abhinavsharmaaadifit-oss.github.io/web-deployment/sites/isalon/`
